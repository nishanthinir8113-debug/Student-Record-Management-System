# Student Record Management System

A simple GUI-based DBMS mini project built with Python, Tkinter, and SQLite.

## Features
- Add student records
- View all records in a table
- Search by student ID or name
- Update selected records
- Delete records
- Store data persistently in a local SQLite database
- Check for duplicate student IDs and missing fields

## Technologies
- Python 3
- Tkinter (GUI)
- SQLite (database; included with standard Python installations)

## How to run
1. Install Python 3 from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py` instead.

The `students.db` database file is created automatically the first time the app runs.
